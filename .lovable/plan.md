# Echat — የAndroid መተግበሪያ ዝግጅት (Capacitor)

ስም፦ **Echat** · የጥቅል መለያ፦ **com.echat.app** · ስሪት፦ **1.0.0** · አዶ፦ አሁን ያለው Echat አርማ

ማሳሰቢያ፦ ትዕዛዙ ክፍል 4 "ሚስጥራዊ ቁልፎችን በAPK ውስጥ ጨምራቸው" ይላል። ይህ ከመግቢያው ማስተካከያ ጋር ይጋጫል፤ የትየባ ስህተት ነው ብዬ ወስጄዋለሁ። ስለዚህ ሚስጥራዊ ቁልፎች፣ የአስተዳዳሪ ፈቃዶችና የክፍያ ማረጋገጫ **በአገልጋዩ ላይ ብቻ ይቆያሉ**፤ ወደ APK አይገቡም።

## 1. ነባሩን ስርዓት መጠበቅ
- Web App እንዳለ ይቀጥላል። የAndroid ለውጦች በስልክ ላይ ብቻ ነው የሚሠሩት።
- የውሂብ ጎታ አይለወጥም፤ የተጠቃሚ መረጃ፣ የWallet ቀሪ ሂሳብና የግብይት ታሪክ አይነኩም።

## 2. Capacitor ማዋቀር
- Capacitor (core, android, cli) ይጫናል፤ ውቅሩ በEchat / com.echat.app ይዘጋጃል።
- የልቀት APK የተገነቡትን የፊት ገጽ ፋይሎች በውስጡ ይይዛል። የpreview አድራሻው የሚከፈተው ለሙከራ ስሪት ብቻ ነው፤ ይህም በተለየ ቅንብር ይበራል።
- አዶውና የመነሻ ማያው ከEchat አርማ ይዘጋጃሉ።

## 3. የሞባይል ተሞክሮ
- የAndroid መመለሻ ቁልፍ፦ መጀመሪያ ክፍት መስኮቶችን ይዘጋል፣ ከዚያ ወደ ቀድሞው ገጽ ይመለሳል፣ በዋናው ገጽ ላይ መተግበሪያውን ይዘጋል።
- የሁኔታ አሞሌ፣ የማያ ጠርዝ ክፍተቶችና ቁልፍ ሰሌዳ ሲከፈት ገጹ በትክክል እንዲስተካከል ይደረጋል።
- ካሜራ፣ ማይክሮፎን፣ ፎቶ/ፋይል መምረጥ፣ አካባቢና ማሳወቂያዎች፦ ፈቃድ የሚጠየቀው ባህሪው ሲከፈት ብቻ ነው። ተጠቃሚው ቢከለክል መተግበሪያው አይበላሽም፤ ግልጽ መልዕክት ይታያል።
- ማሳወቂያዎች በAndroid ላይ ለስልክ በተዘጋጀው የማሳወቂያ ማገናኛ ይሠራሉ። ለዚህ የFirebase `google-services.json` ፋይል ያስፈልጋል፤ ፋይሉን እርስዎ ያቀርባሉ።

## 4. የኋላ ስርዓትና ደህንነት
- አገልጋዩ እንዳለ ይቆያል፤ ሁሉም ግንኙነት በHTTPS ይሆናል።
- መግቢያ፣ ክፍለ ጊዜ ማደስና የGoogle መግቢያ መመለሻ በ`com.echat.app://` አገናኝ በመተግበሪያው ውስጥ እንዲከፈቱ ይደረጋል።
- የAI ዕለታዊ ገደብ፣ Premium፣ Wallet እና Stars እንደ አሁኑ በአገልጋይ ይረጋገጣሉ።

## Technical details
- Deps: @capacitor/core, @capacitor/android, @capacitor/app, @capacitor/status-bar, @capacitor/keyboard, @capacitor/splash-screen, @capacitor/push-notifications, @capacitor/camera, @capacitor/geolocation, @capacitor/browser; dev: @capacitor/cli, @capacitor/assets.
- `capacitor.config.ts`: appId com.echat.app, appName Echat, webDir dist; `server.url` (the lovableproject preview) is set only when `CAP_LIVE_RELOAD=1`, so release builds bundle `dist`.
- `src/lib/native.ts`: `isNative()` from `Capacitor.isNativePlatform()`; the back-button handler uses App.addListener('backButton'); status bar/keyboard init happens in bootstrap.
- Push: on native, `firebaseMessaging.ts` routes to @capacitor/push-notifications and registers the token through the existing `register_device_token` RPC with platform='android'. The web FCM path is unchanged.
- OAuth: on native, open the provider URL with Browser and redirect to `com.echat.app://auth/callback`. An `appUrlOpen` listener calls `exchangeCodeForSession` / setSession. The redirect URL is added to the auth allow-list.
- Android project (`android/`) is generated by the user locally (`npx cap add android`), since the sandbox has no Android SDK. Docs include the AndroidManifest permissions (CAMERA, RECORD_AUDIO, ACCESS_FINE_LOCATION, POST_NOTIFICATIONS) and an intent-filter for the deep link.
- `ANDROID_BUILD.md` covers the steps; keystore files are listed in `.gitignore`.
- Record the architecture rule in AGENTS.md (native code is gated behind `isNative()`; the web path stays untouched).
